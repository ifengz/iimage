# Gemini 批量改图 (iimage)

## 项目说明

`iimage` 是一个面向日常使用场景的 Gemini 批量改图工具。它把“上传图片、填写替换规则、补充说明、批量生成结果图”这几步合到一个页面里，尽量减少反复切图、手工改字、来回沟通和重复点按钮的时间。

这个项目不是为了做一套复杂难懂的专业系统，而是想把批量改图这件事做得更直接、更省事。对需要频繁修改海报、商品图、活动图、社媒图的人来说，它更像一个上手就能用的工作台。

## 项目目的

这个项目的目的，是让更多人都能用更低门槛的方式完成批量改图，不把这件事只留给会写代码或者会复杂设计软件的人。它希望服务更广的人群，包括个体商家、运营人员、内容团队、小团队协作场景，以及需要快速改图的普通用户。

简单说，它想解决的是这几个很常见的问题：

- 一批图片要改同样的内容，但一张一张改太慢。
- 需求是重复的，但每次都要重新沟通、重新操作。
- 会用 AI 的人能提效，不会写代码的人却很难真正用起来。
- 日常改图其实不是少数人的需求，而是很多普通工作场景里的刚需。

## 常用功能与命令

### 生产环境构建
如果您需要打包成静态网页，请运行：
```bash
npm run build
```
打包后的文件将存放在 `dist` 目录下。您可以使用以下命令预览生产版本：
```bash
npm run preview
```

### 核心操作流程
1. **上传图片**：点击 B区（中间面板）的 `+` 号或顶部的 `上传图片` 按钮。
2. **填写指令**：在 `替换规则` 中输入原内容与目标内容，或在 `额外说明` 中填写详细需求。
3. **保存设置**：点击 `保存`。状态将变为 **“就绪”**。
4. **配置 API Key 与并行数**：点击顶部导航栏的设置图标，填入您的 **Google Gemini API Key**，并设置并行数。
5. **开始批处理**：点击底部的 `开始生成` 按钮，等待进度条完成。
